# 📱 ETF量化交易系统（手机版 - 安卓 & iOS）

本工程是专为智能手机（iPhone 与 Android 手机）量身打造的高胜率量化决策系统。

## 🌟 核心特色

1. **精准定位日K线量化决策**：
   - 彻底移除了手机竖屏下体验冗余的“分时图”与“5分钟图”；
   - 专注于高胜率的**日K线决策体系**（包含 MA5/10/20/30、成交量、MACD、KDJ）；
   - K线蜡烛上自动标记 **B1（尾盘低吸）、B2（放量突破）、S1（强势/弱势分级止盈）、S2（放量长上影）、S3（目标落袋50%）、S4（指标止损）、S7（大涨带影减仓）**；
   - 自动绘制持仓成本虚线与盈亏胶囊徽章（`💼 成本: 0.677 (+3.2%)`，右侧对齐防碰撞）；
   - 支持多周期区间统计（1周、1月、3月、半年、1年）与手指滑动十字准星联动。
2. **手机端优先设计（Mobile First）**：
   - 底部固定三大触控导航栏：**【📋 观察池】、【📊 日K线】、【💼 模拟持仓】**；
   - 观察池支持按决策状态（全部、买入、持有、即将满足、观望、卖出）横滑快速过滤；
   - 模拟持仓账户实时核算总资金、可用现金与持仓盈亏，支持一键“发工资”追加资金与重置；
   - 适配全面屏安全区（iPhone 灵动岛/刘海与底部横条 Safe Area）；
   - 深色模式（暗夜）与浅色模式（白天）一键切换。
3. **零服务器依赖（纯端侧轻量计算）**：
   - 手机端直接请求腾讯金融行情接口（原生支持 CORS），毫秒级响应；
   - 指标计算与买卖决策算法在手机本地执行，完全不依赖本地电脑开机或云端付费服务器。

## 🚀 方式一：即开即用（推荐！免证书、免打包、永久可用）

由于移动端已完整配置 **PWA（Progressive Web App）** 与离线 Service Worker，您不需要花费几万元购买苹果开发者账号或在电脑上安装几个 G 的编译工具，只需两步即可在手机上获得**与原生 App 100% 一模一样的全屏独立运行体验**：

### 1. 启动本地手机服务
在电脑端项目根目录执行：
```bash
python serve_mobile.py
```
终端会自动打印出您局域网内的访问地址，例如：
`http://192.168.1.105:8080/index.html`

### 2. 在手机上一键“添加到主屏幕”

- **🍎 苹果 iPhone (iOS)**：
  1. 手机与电脑连接同一 Wi-Fi，打开 iPhone 自带的 **Safari 浏览器**，输入上述链接；
  2. 点击 Safari 底部中间的 **【分享】** 按钮（方框带向上箭头图标）；
  3. 在弹出菜单中向下滑动，找到并点击 **【添加到主屏幕】**；
  4. 点击右上角“添加”，您的 iPhone 桌面就会出现**【ETF量化大师】**独立 App 图标！
  5. 以后直接点击桌面图标打开，无 Safari 网址栏与底部导航栏，像纯原生 App 一样全屏流畅运行。

- **🤖 安卓手机 (Android)**：
  1. 手机连接同一 Wi-Fi，用手机自带浏览器或 **Chrome 浏览器**打开链接；
  2. 点击浏览器右上角菜单键（`⋮` 或三道杠）；
  3. 选择 **【添加到主屏幕】** 或 **【安装应用】**；
  4. 桌面即刻生成 App 图标，具备离线快速加载和全屏沉浸式体验。

> 💡 **外网随时随地访问小技巧**：若希望出门在 4G/5G 流量下也能打开，只需将 `mobile/` 文件夹免费部署至 Vercel、Cloudflare Pages、GitHub Pages 或您的个人服务器，即可在全世界任何地方手机随时查看量化信号！

## 🛠️ 方式二：编译打包为原生应用（APK 与 Xcode 工程）

项目已内置跨平台移动容器配置（`capacitor.config.json`）。若您希望生成 `.apk` 安装包或提交应用商店，可使用以下标准流程：

### 1. 初始化移动工程环境（需 Node.js 18+）
在 `mobile` 目录下运行：
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios
```

### 2. 生成安卓 Android 工程
```bash
npx cap add android
npx cap copy
npx cap open android
```
- Android Studio 会自动打开生成的 `android` 工程；
- 点击菜单栏 `Build -> Build Bundle(s) / APK(s) -> Build APK(s)`，即可生成最终的 `.apk` 安装包传输到安卓手机安装。

### 3. 生成苹果 iOS 工程
```bash
npx cap add ios
npx cap copy
npx cap open ios
```
- 在 Mac 上打开生成的 `ios` 工程；
- 使用个人免费 Apple ID 签名后，点击 Run 即可直接安装到真机 iPhone 运行，或打包生成 `.ipa`。
